01 — SOBRE

O que é C++?

C++ é uma linguagem de programação criada por Bjarne Stroustrup e lançada comercialmente em 1985.

Ela surgiu como uma evolução da linguagem C, adicionando recursos como classes, programação orientada a objetos e templates.

Uma de suas principais características é oferecer ao programador bastante controle sobre os recursos do computador.

Por isso, C++ é encontrada em áreas nas quais desempenho e eficiência são importantes.

04 — NA PRÁTICA

Um programa mais completo 

#include <iostream>
#include <vector>
#include <numeric>

using namespace std;


double calcularMedia(
    const vector<double>& notas
) {

    double soma =
        accumulate(
            notas.begin(),
            notas.end(),
            0.0
        );

    return
        soma / notas.size();
}


int main() {

    vector<double> notas = {

        8.5,
        7.0,
        9.5,
        10.0
    };


    double media =
        calcularMedia(notas);


    cout <<
        "Media: "
        << media
        << endl;


    return 0;
}
